# HSHS Academics Door

A modern, fast academic platform focused on **past papers**, **study notes**, and **student community** — including real-time style chat.

Built with pure **HTML, CSS, and JavaScript** for maximum speed and responsiveness.

## Features
- Clean, AI-inspired interface with glass effects & soft glows
- **Dark & Light mode** (system preference + manual toggle)
- **OKLCH color system** for perceptually uniform, future-proof colors
- **CSS Logical Properties** throughout (inline/block instead of left/right)
- **Container Queries** for truly component-based responsive design
- **Cascade Layers** for maintainable specificity control
- **Chat page** — Instagram-style messaging between members
- Community page with interactive charts (Chart.js)
- Comments section (persisted in browser)
- Smooth scroll animations and modern hero effects
- Fully responsive (mobile-first)
- Fast search and filtering (expanding)

## Pages
- `index.html` — Home (papers, notes, subjects, quick access)
- `community.html` — School community stats & charts
- `comments.html` — Student comments & feedback
- `chat.html` — Member-to-member chat (Instagram-like UI)

## Tech Stack
- HTML5
- Modern CSS3 (OKLCH, logical properties, container queries, cascade layers, nesting-ready)
- Vanilla JavaScript (ES6+)
- Chart.js (community charts)

## Getting Started
Open `index.html` in your browser or serve the folder with any static server.
